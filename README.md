# Village Food – Annavaram

Flutter customer-app MVP starter.

## Current features
- Village Food home screen
- Annavaram sample restaurants
- Food menu
- Cart
- Delivery address
- UPI / Cash on Delivery selection (demo selection only)
- Demo order confirmation/status

## Build on a computer or cloud Flutter environment
1. Install Flutter 3.x.
2. Create the Android host files once:
   flutter create .
3. Get packages:
   flutter pub get
4. Build APK:
   flutter build apk --release
5. APK output:
   build/app/outputs/flutter-apk/app-release.apk

## Important
This is not yet a production food-delivery backend. Real OTP, Firebase orders, UPI payment verification, maps/live tracking, restaurant management, delivery-partner management and admin controls still need to be connected.
